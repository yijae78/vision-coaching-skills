🔑 Claude API 키 발급 방법

  1. console.anthropic.com 접속
  2. 구글/이메일로 회원가입 또는 로그인
  3. 좌측 메뉴에서 API Keys 클릭
  4. Create Key 버튼 클릭 → 키 이름 입력
  5. 생성된 키(sk-ant-api03-...)를 복사
  6. 대시보드 API 키 입력란에 붙여넣기 → 저장

* API 사용료는 Anthropic에 직접 청구됩니다 (약 $0.003/1K tokens)
* 키는 브라우저 로컬에만 저장되며 외부로 전송되지 않습니다
