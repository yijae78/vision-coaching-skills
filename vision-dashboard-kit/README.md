## 3단계: 사용법

### 히어로 페이지 (첫 화면)

1. **API 키 입력** — 하단 입력란에 Claude API 키 입력 후 `저장`
2. **시작 버튼 선택**
   - `8단계 워크플로우 시작` — 8단계 순서대로 코칭
   - `자유 선택으로 시작` — 원하는 스킬만 골라서 코칭
3. **하단 링크** — 8단계 여정 보기, 결과물 샘플 보기 (모달)
4. **줌 버튼** — 우측 하단 `A-` / `A+` 플로팅 버튼으로 화면 크기 조절
5. **Ctrl + 마우스 휠** — 화면 확대/축소 (80%~150%)

### 대시보드 페이지

#### 왼쪽 사이드바 — 개별 스킬 선택
- 8단계별 아코디언으로 65개 스킬 정리
- **단계별 토글 스위치** — 헤더에 3상태 토글 (미선택/부분선택/전체선택)
- 개별 스킬 토글 스위치로 ON/OFF
- 스킬 선택 시 **아코디언 열림 상태 유지** (접히지 않음)
- 미래학 보강 스킬 + 서브스킬 포함
- **전체 펼치기 / 전체 접기** 버튼
- 초기 상태: 모든 단계 접힘 (깔끔한 첫 인상)

#### 오른쪽 메인 영역 — 빠른 선택 + 선택 목록
- **8단계 빠른 선택** — 단계 버튼 클릭 = 해당 스킬 묶음 자동 선택/해제
  - 미선택: 어두운 톤
  - 부분 선택: 컬러 보더 + 카운트
  - 전체 선택: 글로우 효과
- **추천 패키지** — 전체 8단계 / 청년 압축 / 중년 전환 / 은퇴 사역
- **선택된 스킬 목록** — 드래그로 순서 변경, X로 개별 삭제

#### 네비바 (상단 고정)
- `☰ 스킬` — 사이드바 열기/닫기
- `A-` / `A+` — 전체 화면 크기 조절 (사이드바 포함 전체 페이지)
- 디바이스 프리뷰 — 데스크톱 / 태블릿 / 폰 모드 전환
- `↻ 리셋` — 선택된 스킬 전체 초기화
- `선택 N개` + `코칭 시작` — 항상 접근 가능

### 화면 크기 조절 (줌)

| 방법 | 설명 |
|------|------|
| **A- / A+ 버튼** | 네비바 (대시보드) 또는 우측 하단 (히어로) |
| **Ctrl + 마우스 휠** | 페이지 아무 곳에서 Ctrl 누른 채 휠 스크롤 |
| **범위** | 80% ~ 150% (10% 단위) |
| **적용 범위** | 사이드바·네비바·메인 영역 전체 균일 적용 |

### AI 코칭

1. 스킬 선택 후 **코칭 시작** 클릭
2. AI가 첫 질문을 자동 전송
3. 대화창에서 1:1 코칭 진행
4. `닫기`로 대화 종료 (기록 자동 저장)

## API 키 발급 방법

1. [console.anthropic.com](https://console.anthropic.com) 접속 -> 회원가입/로그인
2. 좌측 메뉴 `API Keys` 클릭
3. `Create Key` -> 키 이름 입력 -> 생성
4. 생성된 키 (`sk-ant-api03-...`) 복사
5. 대시보드 API 키 입력란에 붙여넣기 -> 저장

> - API 키는 브라우저 로컬 스토리지에만 저장됩니다 (외부 전송 없음)
> - 사용료: 약 $0.003/1K tokens (Anthropic에 직접 청구)

## 기술 사양

- **단일 HTML 파일** — 빌드 도구·프레임워크 불필요
- **디자인** — 다크 테마, 글래스모피즘, 스카이블루 악센트 (#38bdf8)
- **폰트** — Pretendard Variable (CDN), JetBrains Mono (코드)
- **API** — Claude API (anthropic-dangerous-direct-browser-access 헤더 사용)
- **저장** — localStorage (API 키, 코칭 기록)
- **반응형** — 데스크톱 / 태블릿 / 모바일 지원
- **줌** — transform: scale() 방식, 전체 페이지 균일 확대/축소 (80%~150%)
- **디바이스 프리뷰** — 데스크톱 / 태블릿(768px) / 폰(390px) 시뮬레이션
